## Постановка задачи
Цель работы — освоить программную обработку стандартов обмена лингвистическими данными (TBX и TMX), реализовать алгоритмы нечеткого поиска (Fuzzy Match) и контекстно-точных совпадений (ICE), а также автоматизировать подстановку терминов из глоссария.

## Данные
На основе материалов ЕЭК ООН по теме автомобилестроения и электротранспорта сформированы:
- `variant_10.tbx` — терминологическая база (100 терминов) с переводами, частями речи и определениями.
- `variant_10.tmx` — память переводов (100 параллельных предложений на английском и русском языках).

## Реализованный функционал
1. `parse_tbx()` — извлечение терминологических пар из XML-структуры TBX с корректной обработкой пространств имен (`xml:lang`).
2. `parse_tmx()` — парсинг памяти переводов TMX с формированием колонки контекста (`prev_source`).
3. `calculate_fuzzy_match()` — алгоритм поиска нечетких совпадений на основе расстояния Левенштейна и Token Sort Ratio с поддержкой определения ICE (101%).
4. `apply_term_glossary()` — автоматическая разметка текста переводами из глоссария с защитой от вложенных подстановок (через регулярные выражения и маркеры).

## Полученные результаты
В ходе работы был успешно пройден весь конвейер автотестов, подтвердивший корректность парсинга XML и логики поиска. На тестовых запросах алгоритм показал стабильную классификацию: контекстно-точное совпадение зафиксировано со 100% (ICE), а нечеткое совпадение с изменением одного слова определено как Fuzzy с точностью 89.66%, при этом посторонний текст корректно отсеян как No Match. По итогам обработки базы сформированы готовые к импорту артефакты: экспортирован CSV-глоссарий для Smartcat, а также сформированы сводные таблицы сегментов и отчет по найденным совпадениям.
